## antislop

Skill antislop terpasang di harness, bukan di dalam repo ini.
Core: `~/.dsh/skills/antislop/SKILL.md`, dan skill per bidang ada di folder yang sama.

- UI dan visual: `~/.dsh/skills/antislop-ui/SKILL.md`
- Copy dan teks: `~/.dsh/skills/antislop-copywriting/SKILL.md`
- Aksesibilitas dan kontras: `~/.dsh/skills/antislop-human/SKILL.md`
- Mobile dan responsif: `~/.dsh/skills/antislop-layoutmobile/SKILL.md`
- Komentar kode: `~/.dsh/skills/antislop-code/SKILL.md`

Arah desain proyek ini ada di `DESIGN.md`. Baca itu lebih dulu untuk urusan UI,
lalu pakai antislop sebagai penyaring. Sebelum mulai kerja UI, tanyakan ke pengguna
kapan antislop dipakai: selama kerja, atau setelah selesai.
